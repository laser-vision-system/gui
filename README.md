# GUI 
This the gui repository where the gui related files are stored.
The GUI uses the vue.js java script framework for the front end and a custom java script websocket to connect to the backend, more information on the dependencies used can be found [`here`](/docs/core_dependencies.md)

- For the `development environment setup` click [`here`](/docs/setup.md)
- For the `Docker image deployment` click [`here`](/docs/docker.md)
- For the `Webserver setup` (apache) click [`here`](/docs/webserver_deployment.md).
 Please note that the webserver is contained in the docker image and does not need to be set up, this information is here as to document the repo, please use the docker image if that option is available.
